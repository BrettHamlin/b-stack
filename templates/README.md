# Templates

Starting points to copy into a new project and adapt. They're drafts: expect each project to change them, and expect these to be replaced by versions taken from the first real app ([starter/ios](../starter/ios/)).

| File | Purpose |
|---|---|
| [AGENTS.md](AGENTS.md) | Agent instructions for a new app, including the escalation rule |
| [CODEOWNERS](CODEOWNERS) | Protects the enforcement surface |
| [boundaries.yaml](boundaries.yaml) | Allowed module dependencies and imports, read by the layer-2 import check |
| [feature-map.yaml](feature-map.yaml) | One feature entry for verification |
| [evidence.md](evidence.md) | Evidence package handed back with a change |
